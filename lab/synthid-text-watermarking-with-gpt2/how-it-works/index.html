Step 04 · Autoregressive loop

The pattern emerges across a passage—not in one word.

The winning token joins the context, then the model predicts again. Individual choices remain natural; many small correlations accumulate into detectable evidence.

My favourite tropical fruits are coconut, mangoes, and papaya. Their bright flavours make a simple breakfast feel like summer.
Step 05 · Detection

Replay the scoring lens, then aggregate the evidence.

Given the same private configuration, a detector reconstructs g-values from the text. Watermarked passages tend to score higher; a trained Bayesian classifier can turn that evidence into a likelihood.

The mental model

SynthID changes how tokens are sampled, then looks for the same statistical fingerprint later.

1
It is generative, not post-processing.

The watermark enters during next-token selection rather than being appended as visible characters.

2
The key and configuration are part of the detector.

Each deployed configuration needs a matching trained detector, and the private key material should stay private.

3
Confidence is statistical, not absolute.

Longer, higher-entropy text is easier to detect. Heavy rewriting or translation can weaken the signal.

Important limitation

This page visualizes the mechanism; it does not run the production SynthID detector. No text detector is foolproof, and a result should be treated as evidence—not proof of authorship.
